## 一、项目概述

VoiceDiary 是一款离线优先的智能语音日记应用，支持中文语音转文字、全文搜索、生物识别锁等功能，完全本地存储保护隐私。

**核心理念**:
- 🎙️ 语音输入，解放双手
- 🔒 本地存储，隐私安全
- ⚡ 快速转写，即时可见
- 📱 多端快捷，随时记录

## 三、技术栈

### 开发框架
- **.NET MAUI 8.0.3** - 跨平台 UI 框架
- **CommunityToolkit.Maui 7.0.1** - UI 组件库
- **CommunityToolkit.Mvvm** - MVVM 框架

### 数据存储
- **SQLite + sqlite-net-pcl** - 本地数据库
- **FTS5** - 全文搜索引擎
- **FileSystem** - 文件存储

### 语音识别
- **SherpaOnnx 1.10.10** - Whisper 离线转写
- 模型：sherpa-onnx-whisper-base（多语言中文）

### 压缩备份
- **SharpZipLib** - ZIP 压缩
- **System.Text.Json** - JSON 序列化

### 工具库
- **XCalendar.Maui** - 日期选择器
- **Microsoft.Extensions.Logging** - 日志

## 九、已知限制

### 功能限制

1. **生物识别**
   - 当前使用模拟实现
   - 需要 CommunityToolkit.Maui 配置真机支持

2. **云备份**
   - iCloud 集成待实现
   - OneDrive 集成待实现
   - 当前仅本地 ZIP

3. **iOS Widget**
   - 代码已完成
   - 需要 Xcode 配置 Widget Extension

4. **耳机触发**
   - 仅 Android 支持
   - 依赖硬件兼容性

### 性能限制

1. **大文件转写**
   - 超过 10 分钟音频较慢
   - 建议控制在 5 分钟内

2. **大量数据**
   - 超过 1000 篇加载较慢
   - 已实现分页优化
