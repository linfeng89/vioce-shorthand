# Sprint 3 测试指南

**测试版本**: v0.3.0  
**测试日期**: 2026-05-02

## 准备工作

### 1. 环境检查

```bash
# 检查 .NET SDK 版本
dotnet --version  # 应该 >= 8.0.x

# 检查 MAUI SDK
dotnet workload list  # 应该包含 android / ios

# 检查已连接设备（Android）
adb devices

# 检查已连接设备（iOS）
xcrun simctl list devices
```

### 2. 下载模型文件

如果还没有下载模型：

```bash
cd VoiceDiary
./download-model.sh
```

模型文件应该位于：
```
VoiceDiary/Resources/Models/sherpa-onnx-whisper-base/
├── int8_weights_quant.pt
├── tokenizer.json
├── melody_encoder.json
└── tokens.txt
```

## 编译和部署

### Android

```bash
# 编译 Release 版本
cd VoiceDiary
dotnet build -t:Build -f net8.0-android /p:Configuration=Release

# 部署到设备
dotnet run -f net8.0-android
```

### iOS

```bash
# 编译并部署到设备
cd VoiceDiry
dotnet run -f net8.0-ios
```

### Visual Studio 方式

1. 打开 `VoiceDiary/VoiceDiary.csproj`
2. 选择设备（Android 或 iPhone）
3. 按 F5 运行

## 测试用例

### 1. 录音功能测试

**步骤**：
1. 启动应用，进入主页
2. 按住录音按钮（红色圆形）
3. 说话："今天天气真好，我们去公园吧"
4. 松开录音按钮
5. 等待录音处理完成

**预期结果**：
- ✅ 录音时按钮变色（黄色 #FFC107）
- ✅ 状态显示"录音中..."和计时
- ✅ 松开后变为"处理中..."动画
- ✅ 录音文件保存到 `Recordings/` 目录
- ✅ 自动加入转写队列

**常见问题**：
- ❌ 没有麦克风权限 → 检查应用权限设置
- ❌ 录音文件未创建 → 检查 AndroidManifest 权限声明

---

### 2. 回放功能测试

**步骤**：
1. 在日记列表中找到刚才的录音
2. 点击录音条目进入详情页
3. 点击播放按钮
4. 调节进度条
5. 点击暂停/继续

**预期结果**：
- ✅ 播放进度正常显示
- ✅ 进度条可以拖动
- ✅ 暂停/继续功能正常
- ✅ 可以听到录音内容

---

### 3. 转写功能测试

**步骤**：
1. 录制一段中文语音（30 秒左右）
2. 查看转写队列状态（右上角图标）
3. 等待转写完成
4. 查看转写结果

**预期结果**：
- ✅ 转写状态从"等待中" → "处理中" → "完成"
- ✅ 中文识别准确率 > 80%
- ✅ 转写文字显示在日记详情页
- ✅ 自动保存，无需手动操作

**常见问题**：
- ❌ 转写失败 → 检查模型文件路径和完整性
- ❌ 识别错误率高 → 检查音频质量（16kHz mono）

---

### 4. 列表分组测试

**步骤**：
1. 录制 3-5 条不同时间段的录音

3. 观察分组显示

**预期结果**：
- ✅ 按日期分组（今天/昨天/本周/更早）
- ✅ 每组显示时间段 emoji（🌅☀️🌆🌙）
- ✅ 按时间倒序排列
- ✅ 顶部显示当前月份

### 5. 无限滚动测试

**步骤**：

**预期结果**：

## 调试技巧

### 查看日志

**Android (adb logcat)**：
```bash
adb logcat | grep -i voicediary
```

**iOS (Console.app)**：
1. 打开 Xcode → Window → Devices and Simulators
2. 选择设备 → View Device Logs

### 检查数据库

将数据库文件导出到电脑：
```bash
# Android
adb pull /sdcard/Android/data/com.example.voicediary/files/voice_diary.db ./

# 使用 SQLite 浏览器查看
sqlite3 voice_diary.db ".tables"
sqlite3 voice_diary.db "SELECT COUNT(*) FROM DiaryEntry;"
```

### 检查搜索索引

```sql
-- 检查索引大小
SELECT COUNT(*) FROM DiaryEntry_FTS;

-- 手动测试搜索
SELECT d.* FROM DiaryEntry d
INNER JOIN DiaryEntry_FTS fts ON d.rowid = fts.rowid
WHERE fts.TranscribedText MATCH '天气';
```
