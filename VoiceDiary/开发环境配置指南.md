# VoiceDiary 开发环境配置指南

**适用系统**: Windows 10 22H2 (内部版本 19045.6466)  
**(.NET 版本**: .NET 8.0  
**MAUI 版本**: 8.0.3

---

## 一、系统要求

### 硬件要求
- **CPU**: 1.8 GHz 或更快
- **内存**: 8GB RAM (推荐 16GB)
- **硬盘**: 至少 50GB 可用空间
- **显示**: 1920x1080 或更高分辨率

### 软件要求
- **操作系统**: Windows 10 22H2 (64 位) ✅ 已满足
- **.NET SDK**: 8.0.x
- **Visual Studio 2022**: 17.8+ (可选，推荐)

---

## 二、安装步骤

### 步骤 1: 安装 .NET 8 SDK

1. **下载安装包**
   - 访问：https://dotnet.microsoft.com/download/dotnet/8.0
   - 下载：`.NET SDK 8.0.x` (Windows x64)

2. **安装**
   ```bash
   # 运行下载的安装包
   dotnet-sdk-8.0.x-win-x64.exe
   ```

3. **验证安装**
   ```bash
   dotnet --version
   # 应显示：8.0.x
   ```

---

### 步骤 2: 安装 MAUI 工作负载

```bash
# 安装 .NET MAUI 工作负载
dotnet workload install maui-android

# 安装 Android 工作负载
dotnet workload install android

# 验证安装
dotnet workload list
```

**预期输出**:
```
Installed Workload Id      Manifest Version       Installation Source
--------------------------------------------------------------------
maui-android               8.0.x                  SDK 8.0.x
android                    34.0.x                 SDK 8.0.x
```

---

### 步骤 3: 安装 Android SDK 和 工具

#### 方法 A: 通过 Visual Studio 安装（推荐）

1. **安装 Visual Studio 2022**
   - 下载：https://visualstudio.microsoft.com/
   - 运行安装程序

2. **选择工作负载**
   - ✅ 移动开发与 .NET (Mobile development with .NET)
   - ✅ .NET Multi-platform App UI development

3. **验证 Android SDK**
   ```bash
   # 查看 Android SDK 路径
   echo %AndroidSdkDirectory%
   # 默认：%USERPROFILE%\Android\Sdk
   ```

#### 方法 B: 命令行安装

1. **安装 Android SDK 命令行工具**
   - 下载：https://developer.android.com/studio#command-tools
   - 解压到：`C:\Android\cmdline-tools`

2. **安装必要的 Android SDK 组件**
   ```bash
   cd C:\Android\cmdline-tools\bin
   
   # 接受许可证
   sdkmanager --licenses
   
   # 安装平台工具
   sdkmanager "platform-tools"
   
   # 安装 Android 平台（推荐 API 34）
   sdkmanager "platforms;android-34"
   
   # 安装构建工具
   sdkmanager "build-tools;34.0.0"
   
   # 安装系统镜像（模拟器用）
   sdkmanager "system-images;android-34;google_apis_playstore;x86_64"
   ```

3. **设置环境变量**
   ```bash
   # 添加到系统环境变量
   setx ANDROID_HOME "%USERPROFILE%\Android\Sdk"
   setx ANDROID_SDK_ROOT "%USERPROFILE%\Android\Sdk"
   ```

---

### 步骤 4: 安装 Android NDK

VoiceDiary 的语音识别功能需要 Android NDK。

```bash
# 通过 sdkmanager 安装 NDK
sdkmanager "ndk;25.2.9519653"
```

**或在 Visual Studio 中**:
1. 工具 → Android → Android SDK 管理器
2. 点击 "NDK (Side by side)" 选项卡
3. 勾选版本 25.2.9519653
4. 点击安装

---

### 步骤 5: 安装 Java JDK

.NET MAUI 需要 JDK 17 或更高版本。

1. **下载安装**
   - 访问：https://www.oracle.com/java/technologies/downloads/
   - 下载：JDK 17 (Windows x64)

2. **设置环境变量**
   ```bash
   setx JAVA_HOME "C:\Program Files\Java\jdk-17"
   setx PATH "%PATH%;%JAVA_HOME%\bin"
   ```

3. **验证**
   ```bash
   java -version
   # 应显示：java version "17.x.x"
   ```

## 三、配置 VoiceDiary 项目

### 步骤 6: 还原 NuGet 包

```bash
cd VoiceDiary

# 还原所有 NuGet 包
dotnet restore
```

### 步骤 7: 配置项目 SDK 版本

项目文件 `VoiceDiary.csproj` 已配置为：

```xml
<!-- Android SDK 版本 -->
<SupportedOSPlatformVersion Condition="$([MSBuild]::GetTargetPlatformIdentifier('$(TargetFramework)')) == 'android'">24.0</SupportedOSPlatformVersion>
<TargetPlatformMinVersion Condition="$([MSBuild]::GetTargetPlatformIdentifier('$(TargetFramework)')) == 'android'">24.0</TargetPlatformMinVersion>

<!-- iOS SDK 版本 -->
<SupportedOSPlatformVersion Condition="$([MSBuild]::GetTargetPlatformIdentifier('$(TargetFramework)')) == 'ios'">13.0</SupportedOSPlatformVersion>
<TargetPlatformMinVersion Condition="$([MSBuild]::GetTargetPlatformIdentifier('$(TargetFramework)')) == 'ios'">13.0</TargetPlatformMinVersion>

<!-- Windows SDK 版本（匹配您的系统） -->
<SupportedOSPlatformVersion Condition="$([MSBuild]::GetTargetPlatformIdentifier('$(TargetFramework)')) == 'windows'">10.0.19041.0</SupportedOSPlatformVersion>
```

### 步骤 8: 下载 AI 模型文件

```bash
cd VoiceDiary

# 运行模型下载脚本
./download-model.sh

# 或手动下载
# 访问：https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-whisper-base.tar.bz2
# 下载后解压到：VoiceDiary/Resources/Models/sherpa-onnx-whisper-base/
```

## 四、构建项目

### 方法 A: 命令行构建（推荐）

```bash
cd VoiceDiary

# 构建 Debug 版本
dotnet publish -f net8.0-android -c Debug -o ./publish/debug

# 构建 Release 版本
dotnet publish -f net8.0-android -c Release -o ./publish/release
```

**生成的 APK 位置**:
```
publish/
├── debug/
│   └── com.voicediary.app.apk
└── release/
    └── com.voicediary.app.apk
```

### 方法 B: Visual Studio 构建

1. **打开解决方案**
   ```
   VoiceDiary.sln
   ```

2. **选择配置**
   - 顶部工具栏选择：`Debug` 或 `Release`
   - 选择：`Any CPU` 或特定架构

3. **构建**
   ```
   生成 → 生成解决方案 (Ctrl+Shift+B)
   ```

4. **运行**
   ```
   运行 → 启动而不调试 (Ctrl+F5)
   ```

## 五、部署到 Android 设备

### 准备工作

1. **启用开发者选项**
   - 设置 → 关于手机 → 连续点击 "版本号" 7 次

2. **启用 USB 调试**
   - 设置 → 开发者选项 → USB 调试（开启）

3. **连接设备**
   ```bash
   # 使用 USB 连接电脑
   # 手机上选择"传输文件"模式
   
   # 验证连接
   adb devices
   
   # 应显示:
   # List of devices attached
   # XXXXX device
   ```

### 部署 APK

```bash
# 方法 1: 直接安装
adb install -r publish/release/com.voicediary.app.apk

# 方法 2: 使用 dotnet 发布
dotnet publish -f net8.0-android -c Release /p: deploy-on-change=true
```

## 六、常见问题解决

### 问题 1: .NET 工作负载安装失败

**错误**: `Workload installation failed: Access to the path is denied`

**解决**:
```bash
# 以管理员身份运行命令行
# 清理失败的安装
dotnet workload repair

# 重试安装
dotnet workload install maui-android --skip-sign-check
```

### 问题 2: Android SDK 未找到

**错误**: `The Android SDK directory could not be found`

**解决**:
```bash
# 安装默认 SDK
# 方法 A: 通过 Visual Studio
工具 → Android → Android SDK 管理器

# 方法 B: 命令行
sdkmanager "platforms;android-34" "build-tools;34.0.0"
```

### 问题 3: 构建速度慢

**优化建议**:
```bash
# 1. 启用增量构建
dotnet build --incremental

# 2. 配置 NuGet 包缓存
setx NUGET_PACKAGES "%USERPROFILE%\.nuget\packages"

# 3. 使用 Release 模式
dotnet publish -c Release

# 4. 禁用 R8 压缩（开发时）
/p: AndroidEnablePackageCompression=false
```

### 问题 4: 模型文件下载失败

**错误**: 下载超时或网络问题

**解决**:
```bash
# 方法 1: 使用国内镜像
wget https://mirror.tuna.tsinghua.edu.cn/github-release/k2-fsa/sherpa-onnx/sherpa-onnx-whisper-base.tar.bz2

# 方法 2: 手动下载后放置
# 下载链接：https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-whisper-base.tar.bz2
# 放置位置：VoiceDiary/Resources/Models/
```

### 问题 5: APK 太大（>100MB）

**优化**:
```xml
<!-- VoiceDiary.csproj -->
<PropertyGroup>
  <AndroidPackageFormat>apk</AndroidPackageFormat>
  <AndroidEnableProfiledAot>false</AndroidEnableProfiledAot>
  <RunAOTCompilation>true</RunAOTCompilation>
</PropertyGroup>
```

**或拆分 APK**:
```bash
dotnet publish /p: AndroidCreatePackagePerAbi=true
```

## 九、性能优化建议

### 编译优化

```xml
<!-- VoiceDiary.csproj -->
<PropertyGroup>
  <!-- AOT 编译 -->
  <RunAOTCompilation>true</RunAOTCompilation>
  
  <!-- R8 代码压缩 -->
  <AndroidUseR8>true</AndroidUseR8>
  
  <!-- 链接优化 -->
  <AndroidLinkMode>Full</AndroidLinkMode>
  
  <!-- 使用 LLVM -->
  <UseLLVM>true</UseLLVM>
</PropertyGroup>
```

### 运行时优化

```xml
<PropertyGroup>
  <!-- 启用并发 GC -->
  <AndroidEnableSGenConc>true</AndroidEnableSGenConc>
  
  <!-- 启用 Fast Deployment (仅 Debug) -->
  <AndroidEnableFastDeployment>true</AndroidEnableFastDeployment>
  
  <!-- 使用 64 位运行时 -->
  <AndroidSupportedAbis>arm64-v8a</AndroidSupportedAbis>
</PropertyGroup>
```
