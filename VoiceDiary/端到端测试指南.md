## 测试前准备

### 1. 下载模型

```bash
# 克隆仓库
git clone https://github.com/linfeng89/vioce-shorthand.git
cd vioce-shorthand
git checkout 260502-chore-setup-voice-diary-framework

# 下载中文语音模型
./VoiceDiary/download-model.sh
```

**验证模型**：
```bash
ls -lh VoiceDiary/Resources/Models/sherpa-onnx-whisper-base/
# 应该包含: encoder.onnx, decoder.onnx, tokens.txt (约 153MB)
```

### 2. 编译项目

```bash
# 恢复依赖
dotnet restore VoiceDiary/

# Android 编译
dotnet build VoiceDiary/ -f net8.0-android -c Release

# iOS 编译 (macOS)
dotnet build VoiceDiary/ -f net8.0-ios -c Release
```

### 3. 安装到设备

```bash
# Android (USB 调试已开启)
dotnet build -t:Run -f net8.0-android

# iOS (macOS + Xcode)
dotnet build -t:Run -f net8.0-ios
```

## 测试用例

### 测试 1：短录音→转写→播放 (30 秒)

**步骤**：
1. 打开 App，首页显示红色录音按钮
2. 按住按钮，说："今天天气真好，心情不错"
3. 松开按钮
4. 查看日记列表，刚刚的录音应该显示在第一位
5. 点击条目，查看详情
6. 点击播放按钮，应该能听到刚才的录音
7. 查看转写文字，应该在 30 秒内显示："今天天气真好心情不错"

**预期结果**：
- ✅ 录音成功保存
- ✅ 10 秒内开始转写
- ✅ 转写准确率 > 85%
- ✅ 播放功能正常
- ✅ 时长显示正确

**测试文本**：

### 测试 6：并发录音和转写

**步骤**：
1. 录第一条，说完后松开
2. 立即录第二条（此时第一条正在转写）
3. 录第三条（此时前两条都在转写队列）
4. 等待所有转写完成
5. 检查三条日记的顺序和转写质量

**预期结果**：
- ✅ 录音不受转写影响
- ✅ 三条都正确保存
- ✅ 转写队列按顺序执行
- ✅ 无崩溃、无数据丢失

### 测试 7：App 重启恢复转写

**步骤**：
1. 录 2-3 条日记
2. 在转写完成前杀掉 App
3. 重新启动 App
4. 检查未转写的日记是否自动开始转写

**预期结果**：
- ✅ App 重启后自动扫描未转写条目
- ✅ 转写队列自动恢复
- ✅ 无重复转写
- ✅ 所有日记最终完成转写

### 测试 8：边界情况

**测试 8.1：静音录音**
- 录 10 秒静音
- 预期：转写为空或非常少的文字

**测试 8.2：背景噪音**
- 在嘈杂环境录音
- 预期：转写准确率下降但仍可识别

**测试 8.3：远距离录音**
- 手机放在 2 米外说话
- 预期：可以识别但准确率降低

**测试 8.4：快速连续录音**
- 连续录制 10 条短录音（每条 2-3 秒）
- 预期：全部正常保存和转写

## 性能指标

| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 录音启动延迟 | < 100ms | 按下到开始录音的时间 |
| 录音保存延迟 | < 200ms | 松开到显示"已保存"的时间 |
| 转写启动延迟 | < 10s | 录完到开始转写的时间 |
| 转写速度 | 2-4x 实时 | 1 分钟音频需要 15-30 秒 |
| 播放启动延迟 | < 500ms | 点击到开始播放的时间 |
| 内存占用 | < 300MB | 录音 + 转写同时进行 |
| 电池消耗 | < 5%/分钟 | 连续录音时的电量消耗 |

## 已知问题和限制

### 问题清单

| 问题 | 影响 | 临时解决方案 | 计划修复 |
|------|------|-------------|----------|
| 方言识别差 | 非普通话用户 | 建议说普通话 | P2 优化 |
| 嘈杂环境准确率低 | 地铁/街道等 | 安静环境使用 | P1 降噪 |
| 长时间录音发热 | > 5 分钟连续 | 限制单次时长 | P2 优化 |

### 不支持的场景

- ❌ 多人同时说话（鸡尾酒会问题）
- ❌ 超低音量（耳语）
- ❌ 极快语速（> 300 字/分钟）
- ❌ 专业术语（医学、法律等）
