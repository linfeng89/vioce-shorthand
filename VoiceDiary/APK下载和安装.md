# 📥 APK 下载和安装指南

**版本**: v0.3.0-sprint3  
**更新日期**: 2026-05-02  
**分支**: `260502-chore-setup-voice-diary-framework`

## 方式一：GitHub Actions 自动打包（推荐）

### 步骤 1：访问 Actions 页面

打开：https://github.com/linfeng89/vioce-shorthand/actions

### 步骤 2：选择最新构建

1. 点击左侧 **"Build Android APK"** 工作流
2. 选择最顶部的运行记录（最新的）
3. 等待构建完成（约 10-15 分钟）

### 步骤 3：下载 APK

1. 滚动到页面底部 **"Artifacts"** 区域
2. 点击 **`voicediary-debug-apk`** 下载
3. 解压下载的 ZIP 文件获取 `*.apk`

### 步骤 4：安装到手机

1. 将 APK 传到 Android 手机
2. 打开 APK 文件
3. 允许"未知来源"安装
4. 点击"安装"

## 方式二：手动触发打包

### 触发构建

1. 访问：https://github.com/linfeng89/vioce-shorthand/actions/workflows/build-apk.yml
2. 点击右上角 **"Run workflow"** 按钮
3. 选择分支：`260502-chore-setup-voice-diary-framework`
4. 输入版本号：`v0.3.0-sprint3`（可选）
5. 点击 **"Run workflow"**

### 等待完成

- 预计时间：10-15 分钟
- 状态从 `queued` → `in progress` → `completed`

### 下载 APK

构建完成后按照"方式一"的步骤下载。

## 方式三：本地打包

### 环境要求

```bash
# 安装 .NET 8 SDK
https://dotnet.microsoft.com/download

# 安装 MAUI  workload
dotnet workload install maui-android
```

### 打包命令

```bash
# 克隆代码
git clone https://github.com/linfeng89/vioce-shorthand.git
cd vioce-shorthand
git checkout 260502-chore-setup-voice-diary-framework

# 下载模型 (~433MB)
cd VoiceDiary
./download-model.sh

# 打包 APK
dotnet publish -f net8.0-android -c Debug -o ./publish

# APK 位置
ls -lh ./publish/*.apk
```

## 安装 APK

### 系统要求

- **Android 版本**: 8.0 或更高（API 26+）
- **存储空间**: 至少 1GB 可用空间
- **权限**: 麦克风（必需）

### 安装步骤

1. **传输 APK 到手机**
   - USB 数据线
   - 微信/QQ 文件传输
   - 网盘下载

2. **打开 APK 文件**
   - 在文件管理器中找到 APK
   - 点击打开

3. **允许未知来源**
   - 首次安装会提示"未知来源"
   - 点击"设置" → 开启"允许来自此来源"
   - 返回点击"安装"

4. **授予权限**
   - 首次启动应用
   - 点击"允许"授予麦克风权限

- [ ] **无限滚动**：快速滚动到底部，自动加载更多
- [ ] **空状态**：无日记时显示友好提示

### ✅ 搜索功能

- [ ] **打开搜索**：点击底部 🔍 按钮
